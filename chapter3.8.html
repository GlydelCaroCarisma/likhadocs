CHAPTER III - METHODOLOGY AND SYSTEM DEVELOPMENT (Page 8)

Database Design

Entity Relationship Diagram

This is represented in the Entity Relationship Diagram (ERD), which illustrates the logical data model of the database by displaying the entities (tables), attributes (fields), and relationships of the database. The Likha.ph system has an ERD that illustrates the connection of its main entities, such as Users, Products, Orders, Transactions, Notifications, and Admins, which facilitates understanding the flow of data in the system.

Figure 6. Entity Relationship Diagram (ERD)

Data Dictionary

Data Dictionary contains a detailed description of the elements in the database. It contains information regarding the meaning, type, and size of each and every attribute in the database, for instance, the type of user_id, which may be specified as an integer, or the type of email, which may be specified as a string of a specified maximum length, or the type of order_status, which may be specified as an enumeration of values such as "pending," "paid," "shipped," "completed," "cancelled."

3.4 System Implementation

Frontend Development

The frontend of the system was designed using HTML5, CSS3, and JavaScript, ensuring compatibility across modern browsers and devices. Accessibility features such as clear navigation menus, readable fonts, and responsive layouts were integrated to provide a user-friendly experience.
