CHAPTER III - METHODOLOGY AND SYSTEM DEVELOPMENT (Page 7)

Deployment Diagram

The deployment diagram of the Likha.ph system illustrates how its components are physically arranged and interact: users access the system through a web browser on their device, which communicates with a PHP-based web server that handles requests, processes transactions, and generates frontend pages. The web server connects to a MySQL database server that stores user accounts, product listings, orders, and internal messages. For system-generated emails like account verification and password recovery, the web server also communicates with an SMTP mail server, ensuring secure and reliable email delivery.
