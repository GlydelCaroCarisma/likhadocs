2.1 Related Literature

According to GeeksforGeeks (2024), the Software Development Life Cycle (SDLC) is a structured framework that guides software development from the initial concept to the final deployment and maintenance. It breaks down the development process into clear phases such as planning, requirements analysis, system design, implementation, testing, deployment, and maintenance. Following SDLC ensures that software projects are systematically organized, risks are minimized, and the final product meets user requirements. For a cloud-integrated digital marketplace like Likha.ph, SDLC provides the essential structure needed to manage the complexities of web application development while ensuring quality and reliability.

Within the SDLC framework, Agile methodology is particularly suitable for dynamic web-based applications. Agile emphasizes iterative and incremental development, allowing developers to deliver functional components in short cycles called sprints. This methodology promotes continuous feedback from stakeholders, adaptability to changing requirements, and frequent updates of working software. By using Agile, the development of Likha.ph can respond efficiently to user needs, enhance collaboration between the development team and platform users, and deliver new marketplace features in a timely manner. Agile’s flexibility makes it more effective than traditional Waterfall methods for projects where requirements are expected to evolve. (Atlassian, 2024)

According to Rana et al. (2021), web-based systems are software applications accessed through internet browsers, enabling users to interact with platforms without installing software locally. These systems rely on server-side architecture, ensuring real-time data access, scalability, and cross-device compatibility. Web-based systems are essential for digital marketplaces like Likha.ph, which must accommodate multiple users simultaneously, allow real-time product updates, and integrate cloud services for payments, notifications, and analytics. The accessibility and scalability of web-based platforms make them ideal for connecting local makers with potential buyers efficiently.

According to Patel et al. (2020), Database Management is critical in ensuring the organized storage and retrieval of data for web applications. Likha.ph uses MySQL, an open-source relational database management system, to handle structured data such as user accounts, product listings, and transactions. The system will be developed and tested locally using XAMPP, which provides a bundled environment including Apache, MySQL, and PHP. This setup allows developers to efficiently manage the database, perform local testing, and optimize queries before deploying the system to a live server. MySQL’s reliability and compatibility with web-based applications make it an ideal choice for a marketplace platform that requires secure, consistent, and scalable data management. (Sahu & Tripathi, 2021)
