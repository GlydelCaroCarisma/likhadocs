3.6 System Improvement (Redesign Phase)

Issues Identified

During the initial testing and review of the Likha.ph system, several issues were noted. These included minor inconsistencies in user authentication, limited error handling during order transactions, and occasional delays in notification delivery. Usability concerns were also observed in navigation flow, where some users found it difficult to locate product categories and manage their orders efficiently.

Improvements Applied

To address these issues, the system was enhanced by strengthening the authentication process through secure password hashing and validation methods. Order management functions were optimized to ensure smoother transaction processing, while notification handling was improved to guarantee timely delivery of updates. The user interface was refined to simplify navigation, making product browsing and order tracking more intuitive.

Final System Adjustments

  • Implemented secure password hashing and validation for user accounts.
  • Optimized order and transaction modules to reduce errors and improve reliability.
  • Enhanced notification system for faster and more consistent updates.
  • Refined user interface design to improve accessibility and navigation flow.
  • Maintained all core functionalities, including product listing, order placement, transaction processing, and user management.
