CHAPTER III - METHODOLOGY AND SYSTEM DEVELOPMENT (Page 9)

Backend Development

In the development of the backend, PHP was used which serves as both the application server and database management system. PHP was used to handle server-side logic, including user authentication, product management, order processing, transactions, etc., in addition to generating dynamic HTML content for the frontend. MySQL was used to handle data storage, including user data, product data, orders, transactions, etc., to enable seamless communication between the application logic and the database.

Security Features

  • Authentication - Secure login details are used to verify the user’s identity before allowing access.
  • Authorization - Role-based access control is used to allow administrators, buyers, and sellers to perform operations according to their roles.
  • Data Validation - Both client-side and server-side validation are used to validate data entered by users to avoid any error or malicious activities.

3.5 Usability Evaluation and Data Analysis

Evaluation Method

To evaluate the usability of the Likha.ph system, a survey questionnaire will be used for a selected number of respondents who will represent buyers, sellers, and administrators. The survey will include questions on ease of use, navigation, responsiveness, and satisfaction with the system. An evaluation tool, such as a structured questionnaire or survey form, will be prepared to gather feedback on system usability, functionality, and user satisfaction.

Rating Scale Used

A 5‑point Likert scale will be adopted, ranging from Strongly Disagree to Strongly Agree, to measure user perceptions on ease of use, efficiency, and overall satisfaction with the system.

Data Analysis Tools

The collected responses will be compiled and analyzed using Microsoft Excel or Google Sheets. These tools will facilitate the calculation of average scores, identification of trends, and visualization of results to determine which areas of the system perform well and which require improvement.
