The Seller can sign up, log in, add or edit products, view orders, and message buyers. The Buyer can sign up, log in, browse and search products, view product details, add items to the cart, and checkout. The Admin can log in, approve sellers, message sellers, and manage users. These roles and functions ensure smooth operation of the marketplace platform.

Activity Diagram

Activity diagram is a type of UML (Unified Modeling Language) diagram that visually represents the workflow or sequence of activities in a system. It shows how processes begin, the decisions that guide them, the actions taken, and how they end. The activity diagrams provide a clear description of the roles and their workflows in the Likha.ph system. The Admin handles user, transaction, and report management. The Seller is responsible for handling products and orders while interacting with buyers. The Buyer is responsible for handling shopping activities. Overall, it is a clear description of how each user type will work with the system, making it easy for developers and stakeholders to understand.
