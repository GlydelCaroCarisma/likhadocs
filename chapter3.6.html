CHAPTER III - METHODOLOGY AND SYSTEM DEVELOPMENT (Page 6)

Class Diagram

The class diagram of Likha.ph presents the core structure of the system by defining six main classes: Admin, User, Product, Order, Transaction, and Notification. Each class includes specific attributes that represent the data stored and methods that define its behavior. Admin manages users and monitors transactions, while User represents both buyers and sellers with login and registration capabilities. Product handles item listings by sellers, Order tracks purchases made by users, and Transaction processes payments linked to orders. Notification delivers system messages to users. This diagram provides a clear overview of how different components interact, supporting efficient development and system design.
