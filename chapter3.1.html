CHAPTER III - METHODOLOGY AND SYSTEM DEVELOPMENT (Page 1)

3.1 Development Framework

The development of Likha.ph: A Cloud-Integrated Digital Marketplace for Local Makers follows the Agile Development Model, a flexible and iterative approach that allows continuous improvement throughout the system development process. Agile focuses on delivering functional components in short cycles, enabling the development team to gather feedback, make adjustments, and enhance system features based on user needs. This approach is suitable for the project as it supports adaptability, collaboration, and faster delivery of updates, especially for web-based marketplace systems.

SDLC Phases Applied

Planning Phase. In this phase, the objectives of the system were identified, including the need to create a digital platform that supports local makers in selling their products online. Project scope, resources, and timelines were also defined to guide the development process.

Analysis Phase. The requirements of the system were gathered and analyzed, including user needs such as product listing, user registration, order management, and secure transactions. Challenges faced by local artisans in existing marketplaces were also considered to ensure the system addresses these issues.

Design Phase. The system architecture, user interface, and database structure were designed during this phase. Wireframes and layout designs were created to ensure a user-friendly experience, while the database design was structured using MySQL to handle system data efficiently.

Development Phase. In this phase, the actual coding and implementation of the system were carried out. The developers used web technologies along with XAMPP as the local development environment, integrating features such as user accounts, product management, and transaction processing.

Testing Phase. During this phase, functional testing, usability testing, and performance testing were conducted to ensure that the system works correctly and provides a smooth user experience.
